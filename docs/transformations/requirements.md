# Pre ETL transformation stage requirements

## requirements for transformation stage
 - Type casting: The ability to convert data from one type to another, such as converting strings to integers or dates.
 - Date conversion: Parse multi format dates to specified format.
 - Trimming: Removing leading and/or trailing whitespace from string data.
 - Substring extraction: Extracting a portion of a string. Can be based on position or pattern matching.
 - Upper/lower case conversion: Converting string data to either upper case or lower case.
 - Null value handling: The ability to handle null or missing values, such as replacing them with default values or removing rows with null values.
 - Non-printable character removal: Remove / replace characters that are not visible, such as control characters.
 - Rounding: Rounding numeric values to a specified number of decimal places.
 - New column creation:
    - Fixed values
    - Based on existing columns
        - Concatenation: Combining values from multiple columns into a single column.
        - Arithmetic operations: Performing calculations using values from existing columns to create new columns.
        - Conditional logic: Creating new columns based on conditions applied to existing columns (e.g., using if-else statements).
        - Autogenerated keys: Generating unique identifiers for rows, such as UUIDs or sequential IDs.
        - date functions: Extracting components of dates (e.g., year, month, day) or performing date arithmetic to create new columns.
        - Combination of above methods and functions: Creating new columns using a combination of the above methods, such as concatenating values from existing columns and applying conditional logic to determine the final value.
